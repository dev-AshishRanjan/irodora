# The claims the R9 mockups draw, verbatim

Every list item below is copied from a mockup image, with the mockup's number first — typos
included, because a line that has been tidied is no longer the thing drawn. The claims lint must
refuse each one, and the claims proof plants this file and checks that the lint reports every list
line by its line number (F-219).

This is every construction of F-219’s five classes — a percentage offered as a match, an absolute
colour-vision safety claim, a verdict on a score, a grade borrowed from an institution or an
instrument, a spectrum the camera never takes — that a mockup draws inside a screen or on a
component, found by reading all 28 images. Board prose outside every device frame is not design
(R9-MOCKUP-FIDELITY §2) and is not listed. Claims of other kinds the mockups draw — an identical
hue, an estimate called a measurement, a close match in words — are resolved row by row in the
fidelity contract’s §4 E2 table, not here. The mockups draw these in English only; each line’s Japanese
rendering, in the same order, is in variants.md under *The drawn lines in Japanese*, held to the same
line-by-line bar. A construction of these
classes that a mockup draws and this file lacks is one nobody has checked: add it here before
widening a pattern.
