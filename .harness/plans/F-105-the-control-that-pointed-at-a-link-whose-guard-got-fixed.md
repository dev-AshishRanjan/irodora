## The two failures, separated

Run 30 (`1310b3a`) stopped at **step 4, gate 0 — state**, and skipped the other 26 steps. Run 29
(`4abc565`, the commit before) stopped at **step 6, gate 0 — stale-rationale proof**. They are
different defects, and fixing the first only uncovers the second.

### 1. The lockfile — mine, and avoidable

F-104 added `expo-crypto` to the manifest and committed without the lockfile entry, on the
reasoning that a registry package needs an integrity hash and a peer-resolution key that cannot
be hand-written safely. That reasoning was right; **committing anyway was not.** Golden rule 6
says the build stays green between increments, and E-032 says a manifest and the lockfile move
together. Knowing the rule and citing it does not exempt the commit from it.

### 2. The stale-rationale proof — older, and nobody's fault

`verify-stale-rationale-proof.mjs` has a control case:

> *CONTROL — the honest guard:none link is never touched.* E-009 says its guard is none and must
> keep saying so.

**F-029 wired E-009's guard to `gate:content`.** That is a success — the check the graph was
owed got built. But the control now pointed at a link with a real guard, so planting *"the guard
is not yet blocking"* on it made the checker fire correctly, and the control expected silence.

Re-pointing it at another guardless link would only move the fuse: F-099 and F-101 resolved the
last two, and **the graph now contains none at all**. Which is also a success.

## Approach

**The control constructs the condition it controls for.** It sets `guard: 'none'` on the link it
plants into, rather than hoping production data still contains an example. The subject becomes
E-013 — the same link the positive case uses — so the two cases differ in exactly one variable,
which is what makes it a control rather than a second assertion.

The generalised `withLink` helper replaces `withRationale`'s narrower one; every write still
starts from the pristine `original`, so cases cannot compound.

**The lockfile is generated, not hand-written**, by the pinned pnpm.
